# Complete structured drafting and manual passage markup

## Why

The native navigator displays imported hierarchy but new projects and Add document are flat. An author cannot complete normal folder/document lifecycle or consult materials and resume an exact passage. Existing passage notes do not support the explicitly requested author-defined tagging workflow. A separate character form would not solve the complete writing task (#14, F-50/F-51).

## What changes

Mount source-backed folder/document/note organization and full recoverable CRUD; preserve imported schemas. Add exact reference consultation/return and manual passage tags with project-wide results. Qualify A3-WRITE-01/A3-MARK-01 on a coherent substantial manuscript through native interaction. The later #11 acceptance verifies its readable/canonical handoff, and #7 retains its separate existing-block correction.

F-54 native feedback refines the same outcome: reclaim full tree-row title width through right-click/keyboard actions, replace raw tag text entry with reusable project label names/colors, and make the note inspector compact and understandable. Label colors must be subdued and compatible with the main appearance palettes. Keep the full direct drag behavior selected by F-53.

## Impact

F-55 adds direct one-action passage-mark removal with nearby Undo and immediate local label unassignment. It simplifies the correction loop within the same selected workflow; project-wide catalog operations retain explicit scope and guards.

No new project-kind taxonomy, automatic entity extraction or Canvas engine adoption. Preserve rich data, stable identities, revisions, imported provenance and unknown fields. Additive tagging metadata defaults to empty in older records and survives canonical restore. Existing full parity remains pending. See docs/governance/ALPHA3_STRUCTURED_WRITING_PLAN.md.

F-54 adds schema-11 older-writer protection and a project catalog without rewriting existing annotation/history rows or original imported manifests. Guard shared label changes and retain unused/retired definitions through canonical transfer. Exact previous tag names remain assignment identities; semantic color names are presentation metadata. See ADR-017.
