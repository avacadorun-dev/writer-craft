# Asset and presentation decisions

Keep the supplied1254px RGB master and embedded-raster SVG unchanged. The SVG is a rounded raster container, not a vectorization. Use the existing native AppKit generator, with no runtime dependency added. Full-tile header image is32logical pixels; OS icons use87.5% tile occupancy with transparent exterior. The172px banner mark and existing copy form one centered group.

The supplied blue texture, cream and engraving remain the initial treatment after comparison against actual theme surfaces. Background experiments are review material, not a new theme system. Native texture loading occurs once at startup and propagates decode errors. No per-frame file/decode/network work.

Independent asset review plus exact-source hosted tests/package and actual Light/Dark/minimum-width captures are required. Passing these branding checks does not accept full alpha.3 parity.

The header selects native downsampled 32/64/128 px full-tile renditions by physical pixel density; the 512 px full-tile export is for the banner. This avoids aliasing a dense 512 px engraving down to a 32 px header. The README banner is a measured, centered native AppKit composition generated by `scripts/MakeBanner.swift`; it does not depend on remote fonts or GitHub SVG image nesting.
