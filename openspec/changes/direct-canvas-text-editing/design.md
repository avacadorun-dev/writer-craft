# Direct card input, persistence and history

The separate generic CraftCanvas text editor owns one exact session/node/source draft and a private stable egui widget ID. The host mounts its actual TextEdit inside the reserved/clipped card at the current zoom; there is no floating input over another card. Local scroll, native Unicode selection, clipboard, local Undo and composition own child input instead of dragging/deleting cards. The original primary dialog is removed. Done/Cancel remain discoverable in the board toolbar. Existing source Markdown is exact; no rich-body conversion is implied.

A new-card command creates one provisional editor and acquires its input focus on the creation frame while durable insertion proceeds. Only its exact original record is projected for display; the canonical session remains unchanged. Exact insertion acknowledgement promotes the same editor, preserving its widget identity, selection, composition, local Undo and later text. A double-click on an existing unlocked text card captures the current exact source. OS blur preserves the live draft. Deliberate same-window pointer blur or Cmd/Ctrl-Enter requests finishing. IME preedit/commit frames suppress save/cancel shortcuts and autosave. Escape discards only text not already durably acknowledged. Cancel immediately freezes input and shows an explicit waiting status if a request is in flight; finishing waits for the known outcome. Failure preserves the candidate/draft with retry and preservation actions. Durable insertion/autosaves are not rolled back by Cancel. No text may be accepted after cancellation and silently dropped by a later acknowledgement.

After 600 ms idle outside composition, submit captures the exact current source and prepares against the acknowledged session. A separate worker first writes a full candidate recovery draft using the expected saved head and exact acknowledged draft version, then saves canonically and clears only the matching draft. Only then does the UI Apply the prepared change and acknowledge the exact submitted source. The native input remains available during that worker; later typing is not replaced by its older result, and its TextEdit identity/selection/local Undo remain stable. Subsequent dirty input becomes the next guarded request.

Any failure retains the prepared candidate, exact recovery token and latest native draft. Retry uses that token rather than adopting another observed draft. The current latest text can also be preserved exactly as Markdown; pending board preservation uses the latest valid candidate. Stale bases and another draft cannot be overwritten. Dirty/pending/failed navigation/close is refused; a clean acknowledged in-card editor may leave without losing content. Canonical Undo/Redo operate after editing ends; while the input owns focus, Cmd/Ctrl-Z is local text Undo, including across autosave acknowledgements. Each canonical autosave is an append-only board revision and never rewinds history.

Source/controller tests complement exact-source native journeys: new card→type without dialog, existing card→double-click→Unicode/selection/paste/local Undo, continued typing during slow acknowledgement, composition/OS blur, Done/Cancel, failed/stale save→retry/preserve, restart/recover and board Undo. Inspect compact/wide, Light/Dark and zoom limits with actual compiled captures. No scripted event test or source geometry formula certifies OS IME or native UX.
