# Compiled Markdown manuscript export

Implement issue #20 and the alpha.3 final-manuscript milestone: export a selected manuscript as one readable UTF-8 Markdown document in current tree order, with a sibling assets folder for referenced original images and attachments. This is a reader/editor manuscript export, distinct from the canonical full-fidelity project backup and from the existing folder-shaped portable Markdown export in #11.

The source project, original artifact bytes, histories, notes and imported unknown rich data remain unchanged. Only `studio-transfer` rendering reuse and native export presentation are in scope; no new dependency, schema, storage, Canvas or engine change is selected.

#11 portability, #14 authoring, #19 DOCX and #21 EPUB stay as they are; the shared selection/order plan is authored here so DOCX can reuse it.
