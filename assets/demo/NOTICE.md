# Demonstration artwork

`lighthouse.svg` is original vector artwork created for the WriterCraft synthetic editor showcase. It is distributed under the repository MIT license. It contains no external images, fonts, scripts or network resources.

`lighthouse.png` is the deterministic720×400 raster of that SVG, generated with `@resvg/resvg-js`2.6.2. The application seeds it through the normal owned-image import path for new showcase projects, so the demonstration exercises durable project assets and clipboard/export ownership rather than a special renderer-only source. The original SVG remains the editable artwork under MIT.
